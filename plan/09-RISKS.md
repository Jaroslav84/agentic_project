# Risks & Assumptions Register

Living list. Update as things change — don't let it go stale.

## How to use

- **Risk** — something that *could* break the project.
- **Assumption** — something we're *treating as true* without having proven it. Assumptions that turn out false become risks (or blockers).
- Review at every stage gate (see [04-STAGES.md](04-STAGES.md)). Kill rows that no longer apply.

## Scoring

- **Impact:** H / M / L — how bad if it hits.
- **Likelihood:** H / M / L — odds it hits.
- **Status:** Open / Mitigated / Accepted / Closed.
