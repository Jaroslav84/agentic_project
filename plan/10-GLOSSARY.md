# Glossary

Project-wide vocabulary. A term defined here **overrides** its common English meaning inside any doc in this repo (plan, specs, design, ADRs, code comments).

If you find yourself adding a per-doc "Terms and Definitions" section, first ask: should this term live here instead? Probably yes.

## Rules

- One term, one definition. If two teams use the word differently, pick one and rename the other.
- Keep definitions short — one or two sentences.
- If a term has an abbreviation, put the full form as the heading and note the abbreviation.
- Sort alphabetically.
