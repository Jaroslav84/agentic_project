Sales AI

An autonomous outbound caller that recovers stale proposals, follows up with prospects, and warm-transfers live clients to human reps. Voice pipeline runs on a GPU worker; control plane runs on a CPU droplet.

Status: SPEC v1.0 · Apr 2026 · pilot batch of 30 proposals staged

Stack

  • Voice pipeline — Pipecat (orchestration) · Parakeet RNNT 1.1B (STT) · Inworld TTS (primary) / Kokoro (fallback) · SmartTurn v3 (end-of-turn detection)
  • LLM — Claude Sonnet 4.6 with prompt caching (~45k tokens pre-call)
  • Telephony — Telnyx (outbound + inbound SMS/voice)
  • Compute — RunPod US-CA-2 GPU workers (RTX 4000 Ada, $0.26/hr) · DigitalOcean SFO3 CPU droplet (control plane, PostgreSQL, SalesClaw scheduler)
  • Integrations — FieldTECH (proposals) · HubSpot (deals + contacts) · Matrix (operator alerts)

Run Locally

The controller is static HTML/JS but uses iframes between same-origin pages, so file:// will not work. Serve over HTTP:

cd plan/web
python3 -m http.server 8000
# then open http://localhost:8000/

Login accepts any non-empty password in demo mode.

Conventions

  • No fallback slop. Every path is either the real thing or a clearly-labelled placeholder.
  • Fake data only. Anything in data/ or the Lists tab is synthetic. Do not commit real client PII to this repo.
  • Naming. AI caller = Sales AI. Scheduler daemon = SalesClaw. External CRM = FieldTECH. House sales brand = Pinnacle Services. Keep rename consistency across all docs and code.
  • Spec version. SPEC v1.0 is the current frozen spec. Bump only on material architecture change.
