April 12, 2026 — 7:00 AM Platform Launch
Sales AI v1.0 — Controller Goes Live
The full Sales AI controller went live. Voice pipeline, outbound dialer, warm transfer, and command-and-control — the AI caller starts recovering stale proposals.
🎙️
Voice Pipeline — Pipecat + SmartTurn v3 + Parakeet RNNT STT + Inworld TTS (Kokoro fallback), p50 turn latency ~550ms
☎️
Outbound Dialer — Telnyx-backed, ~45s worker boot-to-armed, sequential one-call-at-a-time per GPU worker
🔄
Warm Transfer — live handoff to human reps with full context and proposal data
🧠
SalesClaw Scheduler — Rust daemon managing RunPod worker lifecycle, batch orchestration, and Matrix command-and-control
🔐
Auth + Session — gate-screen login, session persistence, URL-token auto-login for demos

April 10, 2026 Security
Security Audit — 19 Findings, All Remediated ✓
Before go-live, an independent static-analysis audit was run across all 34 HTML pages, 60+ JS files, and 2 CSS files. 3 critical, 5 high, 8 medium, and 3 low findings — every item either fixed or explicitly accepted.
🛡️
Auth — client-side gate replaced with session-backed flow; password never hashed into client code
🔍
postMessage — all 5 handlers now validate origin; all sends use `window.location.origin` instead of `'*'`
📁
Tokens — inline API tokens stripped from client JS and redacted in display data
✅
XSS — markdown renderer validates URL protocol (http/https/mailto only), `rel="noopener noreferrer"` added to external links
✓ Remediated19 findingsstatic-analysis
